Funcionalidades Principales

🚚 Seguimiento de Carga

Controla el ciclo completo: Preparando → En Camino → Recibido. Soporte para transporte Aereo (+5 dias) y Maritimo (+21 dias) con calculo automatico de fecha estimada de llegada.

✅ Conteo Fisico con Doble Verificacion

El operador ingresa cantidades reales recibidas. Si hay descuadre, el sistema obliga un segundo conteo antes de permitir auditoria. Control total de diferencias por producto.

⚠ Control de Descuadres

Descuadres detectados automaticamente. Si persisten tras el segundo conteo, un colaborador autorizado debe justificar la excepcion con minimo 20 caracteres de explicacion.

📋 Registro de Incidencias

Registra cajas danadas, mercancia en mal estado, faltantes, sobrantes o cualquier incidencia durante la recepcion. Incluye foto de evidencia y estado de resolucion.

📈 Multi-Empresa

Cada empresa de tu base de datos gestiona sus propias cargas de forma independiente. Secuencias separadas, ordenes de compra filtradas y reglas de acceso por empresa.

📄 Informe de Auditoria PDF

Genera un reporte completo con tabla de conteo, diferencias en color, incidencias, excepcion aplicada y zona de firmas para el archivo fisico de auditoria.

Flujo de Auditoria

Recibido  →  Conteo Fisico  →  Descuadre?  →  2do Conteo / Excepcion  →  Auditado ✓

Integracion Nativa con Odoo

Compatible con Compras, Inventario y Correo / Actividades. Validacion automatica de recepciones al marcar como recibido.
